# 口琴谱工作台

Windows 桌面程序：建立与编辑《三角洲行动》口琴谱，导入 MIDI、MusicXML/MXL 或文本简谱，导出项目文件、键位文本谱、PDF 与 PNG，并为曲库中的每首谱设置独立快捷键。程序未做代码签名，Windows 可能显示来源提示。

## 重要风险

游戏官方禁用列表包含自动脚本和鼠标宏。自动演奏可能导致警告、冻结或封号；本程序不保证不会被 ACE 检测，也没有规避检测功能。请先在游戏里打开口琴界面，再手动启用「演奏准备」并使用曲目快捷键。程序无法判断口琴界面是否真的打开。若游戏拒绝系统模拟输入，程序不会尝试绕过。

官方资料：[禁用软硬件列表](https://deltaforce.garena.com/anticheat/zh_tw/announcements/A3FGU4BXEE)、[游戏用户协议](https://store.steampowered.com/eula/2507950_eula_0?eulaLang=schinese)。

## 快速使用

1. 在「我的曲库」新建谱，或导入 `.mid`、`.midi`、`.musicxml`、`.xml`、`.mxl`、`.dfhproj`。
2. 导入 MIDI 后先预览并勾选声部，可分别生成多首谱或合并成一首；选择保留最高、最低或首个音。MusicXML 继续选择一个声部，之后到编辑页校对。
3. 在「谱面编辑」按时间轴任意位置添加音符或休止。拖动音符中间改变时间和音高，拖动左右边缘改变起点或音长；放大、缩小按钮及画布内 `Ctrl + 滚轮` 可调整水平比例。可筛选超音域音符，并查看自动换行的简谱或五线谱。
4. 编辑页的修改先保存在草稿中。点击「保存到曲库」或按 `Ctrl+S` 才写入曲库；离开编辑页或关闭窗口时，未保存的修改会提示保存、放弃或取消。「另存项目文件」用于单独导出 `.dfhproj`。
5. 在曲库卡片点击快捷键框，按下 F1–F24，或 Ctrl／Alt／Shift 加字母、数字、F 键；Delete/Backspace 可清除绑定。若正处于演奏准备，点击快捷键框会先关闭演奏准备。系统已占用的快捷键会拒绝保存。
6. 在「导出分享」保存项目文件、文本键位谱、PDF 或 PNG。
7. 如决定使用自动演奏，先在「设置」确认风险并开启演奏准备，再切回游戏口琴界面按曲目快捷键。若仍在本程序窗口内按键，程序会提示切换前台窗口，不会向本程序发送演奏输入。快捷键会切歌并从头开始，倒计时 3 秒。默认停止键是 `Ctrl+Alt+Shift+F12`；如果系统提示被占用，请在设置中修改停止键，然后再开启演奏准备。

## 口琴与简谱

`Z X C V B N M ,` 对应 `1 2 3 4 5 6 7 高音1`，其中 `1` 固定为 C4。右键升八度、左键降八度、中键升半音；八度与半音可组合。演奏仅使用标准模拟输入。

文本简谱由空格分隔：`1:1 2:0.5 #3:0.5 | ^1:2 0:1`。冒号后是拍数；`^` 升八度，`_` 降八度，`#` 升半音，`b` 降半音，`0` 休止。调名如 `C4`、`F#3`、`Bb4` 在输入窗口单独填写。更多例子见程序的「乐理入门」。

时间轴中的 1 拍统一指四分音符时值；例如 6/8 小节长度为 3 拍，单个八分音符写作 `:0.5`。

简谱和五线谱预览使用相同的小节列宽，并随窗口宽度自动换行；末行不足的位置留白。预览的起点和终点吸附到四分之一拍，最短显示四分之一拍；这只影响记谱显示，原始音符、保存文件及演奏时间保持原值。

画布可独立筛选超出游戏口琴音域的音符，时间轴和键位谱共用该筛选。点击「上一个／下一个」可循环定位并选中问题音符，同时保留缩放比例。判定使用移调后的演奏音高；筛选和定位不会修改谱面或触发保存。

点击时间轴顶部标尺可设置起播线，选择单个音符也会定位到它的起点；「从此处试听」播放当前草稿，跨过起播线的长音会播放剩余部分。「本地试听」仍从头播放。在选择模式下，空白处长按约 350 毫秒后拖动，可框选相交的音符和休止；上下拖动已选音符整体调整音高，点击删除或按 Delete/Backspace 批量删除，Esc 可取消当前框选或拖动。批量编辑支持一次撤销，并需手动保存。

本地试听时，时间轴会自动横向跟随播放线，播放线保持在可视区域左侧约三分之一；手动横向滚动后立即恢复跟随。键位谱、简谱与五线谱同步显示蓝色进度线，并保持各自的查看位置。停止试听后隐藏进度线，保留起播位置和最后的画布位置。

「去除开头空白」会将第一个发声音符移到第 0 拍，移除此前的休止并同步平移后续音符与速度变化；不改变后续演奏节奏。此操作进入编辑草稿，支持撤销，保存到曲库后生效。

## 文件和本地数据

MIDI 预览显示原始轨道数、可导入声部及音符统计，支持查看原始多音和口琴转换结果，并用简易音色试听。默认只选择第一个非鼓声部，不代表它是主旋律；鼓声部需手动勾选，鼓件编号会作为音高导入。确认前不写入曲库，写入失败可重试。支持常见的 MIDI 0/1 格式和按拍计时；格式 2 与 SMPTE 计时暂不支持。

- `.dfhproj`：版本化 JSON 项目，含乐谱、音符、曲速变化和移调。
- `.txt`：逐音起点与音长（拍和毫秒）、音高、键位及鼠标修饰。
- `.pdf`：可自动分页的 A4 乐谱；`.png`：单张长图，最多 300 个事件。
- 曲库保存在当前 Windows 用户的应用数据目录 `口琴谱工作台/library.json`。谱面编辑需要手动保存；按法转换及快捷键设置继续自动保存。不需要账号或联网服务。

## 开发与构建

需要 Windows、Node.js 20+、pnpm，以及 Windows 自带的 .NET Framework 4 C# 编译器。项目使用 Electron、React、TypeScript；输入辅助进程源码位于 `helper/DeltaHarmonicaInput.cs`，使用普通用户态 Win32 `SendInput`。

```powershell
pnpm install
pnpm helper:build
pnpm test
pnpm build
pnpm dev
pnpm package:win
```

如果 pnpm 阻止 Electron 安装脚本，可按其提示批准 Electron 构建脚本并重装。`pnpm package:win` 的结果在 `release/`。

## 设计限制

- 当前每首谱仅支持单声部演奏。MIDI 原始预览可试听多个声部；实际导入会按所选规则处理和弦及重叠音，建议逐音检查。
- 自动演奏必须由用户手动启用。输入辅助进程在停止、前台窗口变化或主程序失联时释放键鼠；它不读写游戏内存、不注入、不使用驱动或提权。
- Windows 不允许低权限进程向高权限目标注入输入；程序不会为此自动提权。
